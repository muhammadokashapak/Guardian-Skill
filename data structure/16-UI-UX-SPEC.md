# UI/UX Specification

## Main screens
1. Dashboard
2. Projects
3. Project Overview
4. Architecture / Codebase Map
5. Audit Runs
6. Findings
7. Finding Detail
8. Fix Review / Approval
9. Change Impact
10. Incident Investigator
11. QA Center
12. Dependencies / Supply Chain
13. Reports
14. Audit Trail
15. Guardian Self-Audit
16. Security Policy / Admin

## Dashboard
Show:
- overall project risk
- critical/high findings
- scan status
- verification status
- dependency risk
- test health
- recent changes
- blocked unsafe actions

## Finding detail
Show evidence, severity, confidence, affected area, remediation, fix plan, tests, approval status and verification history.

## UX safety
- Clearly distinguish AI suggestion from approved action.
- Show exactly what will change before applying.
- Make high-risk actions visually explicit.
- Never display raw secrets.
