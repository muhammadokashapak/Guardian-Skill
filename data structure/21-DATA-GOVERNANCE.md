# Data Governance

## Data classification
- Public
- Internal
- Confidential
- Secret

## Rules
- Minimize data sent to external AI providers.
- Redact secrets and personal/sensitive data where applicable.
- Keep provider selection configurable.
- Record which model/provider processed a task without recording sensitive prompt contents unnecessarily.
- Define retention periods for scans, evidence, incidents and reports.
- Support deletion of ordinary project artifacts without destroying required security audit history.

## AI transparency
Reports should identify AI-derived conclusions versus deterministic scanner evidence.
