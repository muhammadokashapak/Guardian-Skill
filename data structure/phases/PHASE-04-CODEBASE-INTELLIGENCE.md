# Phase 04 — Codebase Intelligence
## Goal
Build a searchable technical model of the codebase.
## Tasks
- AST/indexing adapters
- Module/import graph
- API graph
- Data model map
- Dependency graph
- Test-to-code relationships
- Architecture summary
- Safe semantic retrieval
## Exit criteria
User can ask architecture/flow/impact questions and receive evidence-linked answers.
