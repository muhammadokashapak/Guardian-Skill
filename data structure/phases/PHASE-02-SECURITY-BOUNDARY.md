# Phase 02 — Security Boundary & Policy Engine
## Goal
Build the deterministic authorization layer before powerful AI/tool access.
## Tasks
- Typed action model
- Command allow/deny policy
- File policy
- Network policy
- Approval policy
- Path canonicalization
- Symlink protection
- Secret redaction
- Sandbox interface
- Audit events
## Exit criteria
Unsafe fixtures are blocked; policy failures fail closed; raw secrets never appear in logs.
