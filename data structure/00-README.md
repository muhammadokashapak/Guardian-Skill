# AI Project Guardian — Engineering Intelligence Platform

## Purpose
AI Project Guardian is a security-first Antigravity Skill/Plugin and engineering platform that understands an existing software project, audits it, investigates incidents, analyzes change impact, generates/executes QA checks, evaluates supply-chain risk, proposes safe fixes, verifies them, and continuously re-scans.

## Core Modules
1. Codebase Intelligence Engine
2. Security & Bug Guardian
3. Production Incident Investigator
4. Change Impact Analyzer
5. AI QA Engineer
6. Supply Chain Security Guardian
7. Fix & Verification Engine
8. Self-Audit / Guardian Security

## Core principle
AI may reason about a project, but a deterministic policy boundary decides what it is allowed to read, write, execute, or access over the network.

## Master lifecycle
Discover → Understand → Threat Model → Scan → Correlate → Risk Score → Plan → Approval → Change → Test → Verify → Re-scan → Report
